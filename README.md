## About

I build and run the infrastructure that keeps software online — automating deployments,
tightening feedback loops, and making systems boring to operate.

Most of my time goes to **Linux administration**, **CI/CD pipelines**, and
**containerised deployments**, with a steady focus on monitoring and reliability.
I like problems where the fix is a script that means nobody has to wake up at 3am again.
